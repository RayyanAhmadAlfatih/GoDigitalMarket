# V33.1.1 — LP Builder Per-Block Design & Typography Polish

Tujuan versi ini adalah membawa pengalaman desain dari LP Builder referensi ke U-Growth tanpa merusak engine utama U-Growth.

## Fokus

- Desain section per block.
- Typography judul section.
- Typography deskripsi/teks section.
- Desain tombol per block.
- Desain card/item per block dan per item.
- Preview builder tetap selected-block.
- Public renderer membaca field desain yang sama.

## Guard

- Core landing page storage, revision, SEO, analytics, tracking, A/B testing, publish guard, sitemap, Elementor safe import, dan modul migrasi WordPress tidak dihapus.
- Field desain disanitasi sebelum disimpan.
- HTML Block dan Full HTML Expert Mode tetap melewati sanitizer.

## Catatan

Ini bukan redesign total. Ini adalah polish layer untuk memudahkan admin non-teknis mengatur tampilan LP tanpa menyentuh fungsi growth U-Growth.
