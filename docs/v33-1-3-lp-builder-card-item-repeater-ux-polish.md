# V33.1.3 — LP Builder Card/Item Repeater UX Polish

Versi ini melanjutkan V33.1.2 dengan fokus kecil dan aman: memperbaiki UX repeater card/item di Landing Page Builder.

## Perubahan utama

- Card/item repeater memakai accordion per item agar sidebar tetap pendek walau item banyak.
- Header item menampilkan ringkasan judul/isi item.
- Tambah tombol Buka semua dan Tutup semua.
- Tambah tombol Duplikat item.
- Tombol naik/turun/hapus tetap ada.
- Panel desain & typography per item tetap dipertahankan.
- Marker builder naik ke `data-lp-builder-version="v33.1.3"`.
- Marker public render naik ke `data-lp-renderer="v33.1.3"`.

## Prinsip keamanan

Update ini tidak membongkar SEO, analytics, tracking, A/B testing, public renderer, Elementor Safe Import, Migration Command Center, atau modul migrasi WordPress. Perubahan difokuskan pada layer UX admin builder.
