1. Live preview tombol khusus block Tombol/CTA mengikuti pilihan rata kiri, tengah, atau kanan secara real time.
2. Custom Menu header sticky/fixed diperkuat di builder preview dan public frontend.
3. Custom Menu mendukung item khusus logo saja, sehingga logo tidak harus memiliki label/deskripsi.
4. Custom Menu header punya pengaturan rata menu dan posisi logo.
5. Mini footer/no-distraction footer punya kontrol desain: background, warna teks, warna brand, ukuran teks, dan rata footer.
