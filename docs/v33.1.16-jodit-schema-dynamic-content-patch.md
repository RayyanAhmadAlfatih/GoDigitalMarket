# V33.1.16 — Jodit Upload, Schema Guard & Dynamic Term Content Patch

## Ringkasan
Patch ini menambahkan tiga perbaikan utama untuk template U-Growth:

1. **Jodit editor upload gambar langsung dari toolbar** untuk artikel dan deskripsi produk/jasa.
2. **Schema guard produk/jasa** agar admin bisa memilih Product + Offer, Product tanpa Offer, Service, Course, ItemPage saja, atau tanpa schema khusus produk/jasa.
3. **Dynamic term content server-side** untuk halaman berbasis kategori, tag, keyword/topik, dan slug sehingga konten dinamis tidak hanya bergantung pada landing hardcode/facet tertentu.

## Jodit Upload
Endpoint baru:

- `/admin/jodit-upload`
- alias: `/admin/editor-image-upload`

Upload tetap memakai session admin + CSRF. File JPG/PNG/WebP dikonversi ke WebP lewat image engine existing.

Folder upload default:

- artikel: `assets/uploads/articles/`
- produk/jasa: `assets/uploads/products/`
- editor umum: `assets/uploads/editor/`

## Schema Guard Produk
Field baru disimpan di `seo.schema_mode` pada data produk. Karena `seo` sudah JSON, patch ini kompatibel dengan JSON storage dan MySQL storage existing tanpa kolom baru.

Opsi schema:

- `auto` — auto aman sesuai jenis item
- `product_offer` — Product + Offer, hanya keluar jika harga angka valid
- `product_no_offer` — Product tanpa Offer untuk harga berubah-ubah/by request
- `service` — Service schema tanpa wajib harga
- `course` — Course schema
- `itempage` — ItemPage/WebPage saja
- `none` — tidak mengeluarkan Product/Service schema khusus

## Dynamic Term Content
Route baru:

- `/tag/{slug}/`
- `/keyword/{slug}/`
- `/topik/{slug}/`
- `/kategori/{slug}/` fallback jika tidak ada SEO landing registry yang cocok

Sumber pencocokan:

- produk/jasa: kategori, subkategori, tipe item, lokasi, tag, keyword, meta keyword, slug, judul, deskripsi, konten
- artikel: kategori, tag, keyword, focus keyword, meta keyword, slug, judul, excerpt, konten

Sitemap utama juga menambahkan sebagian URL term dinamis yang punya konten terkait.
